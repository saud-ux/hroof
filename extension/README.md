# إضافة المتصفح — اختصارات البَزّر وأنت داخل لعبة أخرى

## المشكلة التي تحلّها

اختصارات صفحة التحكم (المسافة للتجهيز، والهروب للإلغاء… إلخ) مبنية على استماع الصفحة لضغطات الكيبورد، والصفحة لا يصلها أي ضغط إلا وهي **النافذة النشطة**. فلمّا تكون داخل لعبة على الشاشة الرئيسية، كل الضغطات تروح للّعبة، وصفحة "حروف" على الشاشة الثانية لا يصلها شيء.

هذا قيد في نظام التشغيل نفسه، لا في الكود: أي صفحة ويب لا يمكنها التقاط الكيبورد وهي في الخلفية.

الشيء الوحيد الذي يقدر يلتقط اختصارات عامة والمتصفح في الخلفية هو **إضافة متصفح** تسجّل اختصارات

global

على مستوى النظام — وهذا ما تفعله هذه الإضافة: تلتقط الضغطة، ثم توجّهها لتبويب صفحة التحكم فينفّذ نفس منطق الاختصارات الأصلي.

## طريقة التثبيت

الإضافة غير منشورة على المتجر، فتُثبَّت يدويًا (وضع المطوّر):

1. افتح متصفح

   Chrome

   أو

   Edge

   واذهب إلى `chrome://extensions`.

2. فعّل **وضع المطوّر**

   (Developer mode)

   من الزاوية.

3. اضغط **تحميل غير مضغوطة**

   (Load unpacked)

   واختر مجلد `extension` هذا.

4. تظهر الإضافة باسم «حروف — اختصارات البَزّر».

## الاستخدام

- افتح صفحة التحكم في تبويب على المسار `/buzz/host` (أو `/bzhost`).
- شغّل لعبتك على الشاشة الرئيسية كالمعتاد.
- استخدم الاختصارات وأنت داخل اللعبة:

| الأمر | المفتاح الافتراضي |
| --- | --- |
| تجهيز البَزّر | `Ctrl+Shift+1` |
| إلغاء/إيقاف الجولة | `Ctrl+Shift+2` |
| الجولة/السؤال التالي | `Ctrl+Shift+3` |
| احتساب نقطة | `Ctrl+Shift+4` |

على

macOS

استبدل `Ctrl` بـ `Control` (نفس المفتاح، وتجنّبنا `Command+Shift+3/4` لأنها للقطات الشاشة).

اضغط أيقونة الإضافة لترى المفاتيح وحالة صفحة التحكم.

## تغيير المفاتيح أو إضافة اختصارات أخرى

اذهب إلى `chrome://extensions/shortcuts` (أو زر «تعديل المفاتيح» في نافذة الإضافة). هناك تقدر:

- تغيّر أي مفتاح بما يناسبك ولا يتعارض مع لعبتك.
- تفعّل بقية الأوامر التي بلا مفتاح افتراضي: إظهار الإجابة، والصعوبة (سهل/متوسط/صعب)، والمؤقّت (٥/١٠ ثوانٍ).
- تأكد أن نطاق كل اختصار **Global** (عام) لا **In Chrome**، حتى يعمل والمتصفح في الخلفية.

## ملاحظات ومحدوديات

- شرط عمل الاختصارات العامة: أن يكون المفتاح مع `Ctrl+Shift` (أو `Ctrl+Alt`). لهذا لا يمكن جعل المسافة أو الهروب وحدهما اختصارًا عامًا — استعضنا عنها بالأرقام.
- تجنّبنا `Alt+Shift` عمدًا لأنه على

  Windows

  يبدّل لغة الكيبورد.
- بعض الألعاب بوضع ملء الشاشة الحصري

  (exclusive fullscreen)

  تحتكر الإدخال وقد تمنع وصول الاختصار. جرّب وضع النافذة أو ملء الشاشة بلا حدود

  (borderless)

  إن لم يعمل.
- الاختصارات تعمل مهما كان مصدر اللعبة: تطبيق مستقل، أو تبويب آخر في نفس المتصفح.
