# لعبة الخلية — بزّر

نظام بزّر محلي (لا يحتاج إنترنت) للعبة الخلية العربية.
تسجل كل الفرق المشاركة في الفعالية مرة واحدة، وفي كل جولة تختار **فريقين ١ ضد ١**.
كل فريق يفتح رابط الفرق من جواله ويختار اسمه من القائمة — بدون كتابة.

## الروابط

بعد التشغيل، عندك رابطين مستقلين:

| الرابط | لمين | ملاحظة |
|--------|------|--------|
| `http://<IP>:3000/host` | المقدم فقط | لا تعرضه — يحوي الأسئلة والإجابات |
| `http://<IP>:3000/team` | كل الفرق | هذا اللي في الـ QR |

الجذر `/` يعرض شاشة الفرق تلقائيًا، فحتى لو أحد فتح الـ IP فقط ما يشوف إلا شاشة الفرق.

## المتطلبات

- Node.js **v20** أو أحدث.
- كل الأجهزة على نفس شبكة WiFi (أو Hotspot اللابتوب).

## التثبيت والتشغيل

```bash
npm install
npm start
```

عند التشغيل ترى:

```
Cell Buzzer running:
  Presenter (private) : http://localhost:3000/host
                        http://192.168.1.x:3000/host
  Teams (share)       : http://192.168.1.x:3000/team
  Loaded 2903 questions.
```

## طريقة الاستخدام

### ١. الإعداد (مرة واحدة)
1. المقدم يفتح `/host` من لابتوبه.
2. يضيف كل الفرق المشاركة (٢ إلى ٨) — لكل فريق اسم ولون. `+ إضافة فريق` يضيف صف جديد، والعلامة `×` تحذفه.
3. `حفظ الفرق وبدء الفعالية` → ينتقل تلقائيًا لشاشة المقدم.

### ٢. الفرق تنضم
1. كل جوال يفتح `/team` (أو يمسح الـ QR على شاشة المقدم).
2. تظهر بطاقات كل الفرق — كل جوال يختار فريقه بالضغط على البطاقة.
3. المقدم يشوف بجانب كل فريق دائرة ملونة إذا الفريق متصل.

### ٣. كل جولة
1. المقدم يضغط على بطاقتين → تصبح واحدة `أ` والثانية `ب`.
2. `بدء المباراة` → تنشط شاشة اختيار الصعوبة.
3. المقدم يختار الصعوبة → يظهر السؤال والإجابة على شاشة المقدم فقط. جوالات الفريقين تنشط فيها زر **بز!**.
4. أول فريق يبزّ:
   - جواله يمتلئ بلون فريقه: **بزيت أولاً!**
   - جوال الفريق الآخر يقفل بلون أحمر: **الخصم بز أولاً**
   - يبدأ مؤقت **٥ ثوانٍ** على شاشة المقدم فقط.
5. المقدم يحكم شفويًا. الخيارات:
   - إجابة صحيحة → `السؤال التالي`.
   - انتهى الوقت → صفارة، ثم يظهر زر **بدء وقت [اسم الفريق الآخر]** بلون ذلك الفريق → ٢٠ ثانية.
   - في أي لحظة يقدر يضغط `السؤال التالي` بدون صوت.

### ٤. بين الجولات
- `إنهاء المباراة` من الرأس → يرجع لصفحة اختيار الفريقين.
- الفرق تبقى متصلة، فقط اختر بطاقتين جديدتين للمواجهة القادمة.

### ٥. الإعدادات (⚙)
- `جلسة جديدة` → يمسح كل شيء (الفرق + الأسئلة المستخدمة) ويرجع لصفحة `/host`.

## الأصوات
- الملف: `public/audio/timer-end.mp3` (اختياري).
- إذا الملف غير موجود، يتم توليد نغمة قصيرة من متصفح كل جهاز عبر Web Audio API.

## الخطوط
- ضع ملفات `Cairo-Regular.woff2` / `Cairo-Bold.woff2` / `Cairo-Black.woff2` في `public/fonts/`.
- بدونها ينتقل تلقائيًا إلى `Tajawal` أو خط النظام.

## Firewall
- عند أول تشغيل قد يسألك النظام بالسماح لـ Node.js في **المنفذ 3000** — اقبل.
- إذا الفرق ما قدروا يوصلوا: تأكد أن كل الأجهزة على نفس الشبكة، وأن الجدار الناري يسمح بالمنفذ 3000.

## عزل بيانات الفرق
- جوالات الفرق **لا يصلها**: نص السؤال، الفئة، الصعوبة، الخيارات، الإجابة، تلميح، أو أي مؤقت.
- الأحداث الوحيدة التي يستقبلها جوال الفريق: `question:showTeams` (payload فارغ فقط للتنبيه)، `buzz:winner`، `timer:end` (لتشغيل الصوت فقط)، `question:cleared`.
- الفرق خارج المباراة الحالية لا يصلها حتى `question:showTeams` — تظل شاشتهم على "مباراة فريق آخر".

## ثوابت النسخة
- المؤقتات ثابتة: **٥ ثواني** ثم **٢٠ ثانية**.
- لا يوجد نظام نقاط — الحُكم شفوي.
- كل مباراة **١ ضد ١**، بغض النظر عن عدد الفرق المسجلة.
- ريفريش جوال الفريق يرجعه لصفحة اختيار الفريق.
